# MusicStream – Acme Records Digital Experience

## Descripción del Proyecto

Acme Records, una compañía legendaria en la industria musical, decidió reinventar su presencia digital creando **MusicStream**, una plataforma híbrida que integra el streaming moderno con una tienda de música digital tradicional.

El objetivo del proyecto fue consolidar múltiples propuestas de diseño (wireframes independientes) en una única aplicación web coherente, unificando la experiencia bajo un sistema visual **Dark Mode** sólido y moderno.

La problemática principal era la fragmentación del usuario: escuchar música en una app y comprarla en otra plataforma distinta.

### Solución Implementada

Se desarrolló una interfaz unificada donde el usuario puede:

- Explorar música
- Escuchar previews en el reproductor
- Comprar álbumes en la misma sesión
- Gestionar su biblioteca personal

Todo dentro de una experiencia visual moderna, oscura y consistente.
