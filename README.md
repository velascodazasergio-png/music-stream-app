# 🎵 MusicStream — Acme Records

## Descripción del Proyecto

**Acme Records** es una compañía legendaria en la industria musical que decidió renovar su presencia web lanzando **MusicStream**: una plataforma híbrida que combina un servicio de streaming con una tienda de música digital.

Los usuarios pueden escuchar canciones en línea y también comprarlas para tener propiedad sobre ellas, todo dentro de una sola interfaz unificada en **Dark Mode**, diseñada para reducir la fatiga visual con acentos de color vibrantes.

## 🛠️ Tecnologías Utilizadas

- **HTML5 Semántico** — Uso de etiquetas como `<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, `<footer>`
- **CSS3 Puro** — Sin frameworks externos (sin Bootstrap, sin Tailwind)
- **CSS Flexbox & Grid** — Para layouts responsivos multi-columna
- **CSS Animations & Keyframes** — Disco vinilo giratorio, bordes animados, carrusel 3D
- **CSS :checked trick** — Carrusel 3D de artistas completamente sin JavaScript
- **Diseño Responsivo** — Mobile First, funcional desde 375px hasta escritorio
- **Font Awesome 6.5** — Iconografía del reproductor y navegación
